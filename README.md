# FoamSim-Agent

**Can AI coding agents run trustworthy micromechanics simulations of hollow-particle composites?**

A validated, composable Python toolkit for syntactic-foam micromechanics (`foamsim`), agent skills that teach a
coding agent its API, and a benchmark of agent-generated simulation pipelines graded on code features, execution,
and agreement with analytical references *and* experimental data (FoamGPT).
